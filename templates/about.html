FEATURE ENGINEERING

The 9 Lexical URL Extraction Features

To eliminate network vulnerabilities such as SSRF and remote exploits, the URL classification engine analyzes web addresses strictly through static lexical parsing:

01

URL Length

Phishing URLs frequently use elongated paths to conceal true destination domains or pass extensive tracking parameters.

02

Dot Count (.)

Measures period delimiters. Attackers stack subdomains (e.g. paypal.com.verify-user.top) to deceive victims.

03

Hyphen Count (-)

Hyphens are rarely used in authentic root brands, but frequently appear in typo-squatting domains (e.g. apple-id-login).

04

Digit Count (0-9)

Automated phishing kits and algorithmically generated domains (DGAs) incorporate numerous digits into hostnames.

05

Presence of IP Address

Legitimate organizations rarely host production consumer services on raw IPv4 addresses without a domain name.

06

HTTPS Usage

Verifies whether the address uses secure transport encryption (HTTPS) or legacy, unencrypted HTTP transmission.

07

Suspicious Characters

Quantifies special tokens (@, //, ~, %, =, ?, &) often leveraged in URL obfuscation, redirection, and token masquerading.

08

Phishing Keywords

Scans for security-sensitive trigger words: login, verify, banking, secure, wallet, ebayisapi.

09

Subdomain Depth

Parses the domain authority hierarchy. A depth exceeding 2 subdomains strongly indicates domain masquerading.

ETHICS & SECURITY POLICY

Operational Safety & Defensive Principles

Zero-Execution Isolation

Submitted URLs are parsed purely as text strings. The system never establishes TCP/IP connections, resolves DNS, or downloads remote assets. This completely neutralizes SSRF, drive-by malware, and beaconing.

User Privacy & Data Minimization

Only the submitted inquiry string, timestamp, and resulting prediction are stored in SQLite. No IP addresses, cookies, session identifiers, or personal user identifiers are collected or tracked.

Probabilistic Model Nature

Machine Learning models calculate statistical probabilities based on historical patterns. While achieving high accuracy, they do not guarantee detection of every novel zero-day attack or sophisticated evasion.
